### Research

Each of these began as a result and turned into a finding about the method
behind it. The controls were built so that they could fail, and where they did,
that is what the repository reports.

- **[crop-fusion-bench](https://github.com/thinkiamparanoid2/crop-fusion-bench)** — image and
  greenhouse-sensor fusion for crop-disease diagnosis, with a parameter-matched
  8-qubit VQC head against its classical twin. The headline is an audit of the
  benchmark itself: 98% of test samples share a sensor recording with training,
  and a lookup table on that recording reaches 94.0% test accuracy with no
  learning at all, against the trained sensor model's 94.4%.

- **[prototype-aggregation-cl](https://github.com/thinkiamparanoid2/prototype-aggregation-cl)** — which
  prototype rules keep a continual learner from collapsing, over 120 controlled
  cells. Projecting into 10,000 dimensions does not prevent collapse, and
  bounded aggregation alone only partly does; hyperdimensional computing matches
  an exact-median learner while keeping one vector per class instead of every
  sample it has seen.

- **[hcc-kinase-conformal-screen](https://github.com/thinkiamparanoid2/hcc-kinase-conformal-screen)** —
  conformal applicability domains for virtual screening of natural products
  against three liver-cancer kinases. The domain filter turns out to depend on a
  tolerance parameter that published work rarely states: at the value used here
  it switches itself off on two of three targets, admitting the whole library as
  "in domain".

### Builds

- **[Quantum Physics Lab](https://github.com/thinkiamparanoid2/quantum-physics-lab)** —
  interactive quantum physics and quantum computing in the browser, in vanilla
  JavaScript with zero build dependencies: wave-particle duality, Bell tests,
  Bloch sphere visualisations and surface-code error correction, with
  experiments run on IBM's `ibm_kingston` processor.
  [Live site](https://quantum-physics-lab.vercel.app)

- **[Compiler Design](https://github.com/thinkiamparanoid2/Compiler-Design)** —
  a C compiler frontend: lexical analysis (`Flex`), LALR parsing (`Bison`),
  scope-nested symbol tables, type checking, and three-address code generation.

- **[Personalizer](https://github.com/thinkiamparanoid2/Personalizer)** —
  offline-first PWA workspace for academic tracking and credential management,
  with a stale-while-revalidate service worker and Firestore persistence.

- **[SiteForge](https://github.com/thinkiamparanoid2/SiteForge)** —
  construction resource planning: inventory tracking, procurement workflows,
  BOQ generation and field workforce management, on Node.js, Express and MySQL.

- **[Vector Velocity](https://github.com/thinkiamparanoid2/OpenGl_Racing_Game)** —
  a 3D arcade racing engine written from scratch in Python and PyOpenGL, with
  procedural tracks, raycast collision physics and waypoint-driven AI opponents.
