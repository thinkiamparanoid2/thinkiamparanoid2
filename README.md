### Featured Projects

- **[Quantum Physics Lab](https://github.com/thinkiamparanoid2/quantum-physics-lab)**  
  39 interactive quantum physics and quantum computing simulations in browser vanilla JavaScript — covering wave-particle duality, Bell tests, Bloch sphere visualizations, and surface code quantum error correction. Zero build dependencies.

- **[Compiler Design](https://github.com/thinkiamparanoid2/Compiler-Design)**  
  Complete C compiler frontend implementing lexical analysis (`Flex`), LALR syntax parsing (`Bison`), scope-nested symbol table management, type checking, and Three-Address Code (TAC) intermediate representation.

- **[Vector Velocity (OpenGL Racing Game)](https://github.com/thinkiamparanoid2/OpenGl_Racing_Game)**  
  Real-time 3D arcade racing game engine built from scratch with Python and PyOpenGL. Features procedurally generated tracks, raycast collision physics, and waypoint-driven AI opponents.

- **[SiteForge](https://github.com/thinkiamparanoid2/SiteForge)**  
  Enterprise construction resource planning platform supporting real-time inventory tracking, procurement workflows, Bill of Quantities (BOQ) generation, and field workforce management. Built with Node.js, Express, and MySQL.

- **[Personalizer](https://github.com/thinkiamparanoid2/Personalizer)**  
  Offline-first Progressive Web App (PWA) workspace for academic tracking and credential management with service-worker cache fallback and Firebase synchronization.
